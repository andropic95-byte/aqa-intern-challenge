# AQA intern challenge

Решение тестового задания для стажировки QA Fullstack в Учи.ру.

## Что сделано

- исправлены локаторы и ожидания в существующих тестах;
- добавлена проверка закрытия и повторного открытия виджета;
- настроено сохранение скриншота и trace при падении теста;
- добавлены команды для запуска тестов и просмотра отчёта.

## Запуск

```bash
npm ci
npx playwright install chromium
npm test
```

Запуск в браузере:

```bash
npm run test:headed
```

HTML-отчёт:

```bash
npm run test:report
```

## Результат

```text
3 passed
```

Тесты запускаются на Chromium и работают с сайтом `uchi.ru`.
